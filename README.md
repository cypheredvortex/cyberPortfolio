# MyPortfolio

Professional portfolio website for Achraf Sghiri, focused on cybersecurity and network infrastructure.

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

The application is available at `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run build
```

## Environment variables

No environment variables are currently required. If any are added later, keep local values in `.env.local` and document variable names in `.env.example` without committing secrets.

## Deployment

The repository root is a standard Next.js application root. Vercel detects Next.js automatically; no `vercel.json` configuration is required.
